# SDG Interactions Driven by Urban Typologies

This repository contains the R and Python code used for the analyses in this manuscript.

## Code
- `UrbanTypology_SDGinteractions.R`  
  Data preprocessing, clustering, and SDG interaction analyses.
- `CitySDGResults_cleaned.ipynb`  
  Python analyses and figure generation.


## Software 
- R 
- Python / Jupyter Notebook


## Reproducibility

The repository uses relative paths for both R and Python analyses.

Recommended workflow:

1. Open the RStudio project file.
2. Run `code/UrbanTypology_SDGinteractions.R`.
3. Open and run `code/CitySDGResults_cleaned.ipynb`.
4. Input data are stored in the `data/` directory.
5. Generated outputs are saved to the `results/` directory.
