# SDG Interactions Driven by Urban Typologies

This repository contains the data and R/Python code used for the analyses in this manuscript.

## Repository Structure

- `code/` – R and Python analysis code
- `data/` – input datasets used in the analyses
- `environment/` – required R and Python packages
- `results/` – outputs generated by the analysis

## Code

### R

`code/UrbanTypology_SDGinteractions.R`

Contains the main data processing, clustering, SDG interaction, network, and related statistical analyses.

### Python

`code/CitySDGResults_cleaned.ipynb`

Contains additional analyses and visualization procedures used to generate manuscript results and figures.

## Data

The `data/` directory contains the datasets used in the analyses.

- `Original_data/` – original city-level SDG indicator datasets and indicator metadata
- `ParkServe_fgd_DataShare/` – ParkServe-related datasets
- `Data_for_figures_4results/` – processed datasets used to generate manuscript figures and results

## Software and Dependencies

The analyses were conducted using R and Python.

Required packages are listed in:

- `environment/R_packages.txt`
- `environment/requirements.txt`

## Reproducibility

The repository uses relative paths so that the analyses can be reproduced after cloning the repository.

Recommended workflow:

1. Clone or download this repository.
2. Open `SDG_Interactions-driven-by-Urban_Typologies.Rproj` in RStudio.
3. Run `code/UrbanTypology_SDGinteractions.R`.
4. Open and run `code/CitySDGResults_cleaned.ipynb`.
5. Input data are read from the `data/` directory.
6. Generated outputs are saved to the `results/` directory.
